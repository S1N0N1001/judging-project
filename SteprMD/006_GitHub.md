# 006. Подготовка к отправке в GitHub

Дата: 03.11.2026.

Целевой репозиторий: https://github.com/S1N0N1001/judging-project

- Проверены репозиторий и разрешения подключения. Репозиторий пустой, ветка по умолчанию main.
- GitHub-подключение Developer-lab-online сообщает только чтение; отдельно проверяется доступ через Git Credential Manager на компьютере.
- Расширен .gitignore: базы, окружения, EXE/сборки, логи, секреты и локальные данные исключены.
- Добавлен .gitattributes для нормализации текстовых файлов.
- README дополнен инструкцией для получения исходников из Git; файлы сборки не выдаются за часть клонируемого репозитория.
- Перед коммитом проверяется список файлов и отсутствие реальных токенов/паролей. Тестовые строки в тестах являются фиктивными данными.
- Состояние отправки будет зафиксировано после проверки Git-доступа. Рабочий db.json и данные мероприятия не публикуются.


## Результат подготовки и попытки отправки

- Git инициализирован локально; ветка main, origin указывает на заданный репозиторий.
- В первоначальном коммите `40345c4` сохранены 29 файлов. Автор — подключённый аккаунт Developer-lab-online с публичным GitHub noreply-адресом.
- Проверены индекс Git и отсутствие реальных кодов доступа из исходного db.json среди публикуемых файлов.
- Отправка `git push -u origin main` отклонена GitHub: Invalid username or token; Authentication failed. Данные в удалённый репозиторий не отправлены.
- GitHub-плагин отдельно подтвердил отсутствие push-разрешения для Developer-lab-online.
- Для завершения требуется подключить аккаунт S1N0N1001 либо предоставить Developer-lab-online право Write к репозиторию и доступ приложению. Альтернатива — выполнить вход в Git Credential Manager под аккаунтом с правом записи.
- После исправления доступа достаточно повторить push; локальный проект уже подготовлен. Пароли и токены в файлы проекта не записывались.
