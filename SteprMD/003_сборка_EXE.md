# 003. Лаунчер, сборка и проверки EXE

Дата: 03.11.2026.

## Выполнено

- Создан launcher.py: отдельный управляемый сервер, проверка готовности, открытие браузера, единственный экземпляр на каталог данных, обработка занятого порта, кнопки открытия и остановки.
- Служебный HTTP-канал слушает только loopback и требует отдельный случайный секрет. Проверка чужого приложения на занятом порту не сводится к HTTP 200.
- Добавлены локальные операции восстановления базы и сброса пароля, недоступные через веб-форму.
- Добавлены Judging.spec, build.ps1, requirements.txt и актуальная инструкция README.md.
- Установка зависимостей выполнена в новой .build-venv. Комплектная старая .venv не изменена.
- Поставка onedir: dist/Judging/Judging.exe вместе с папкой _internal. Реальная база и исходный db.json в сборку не включены.

## Обнаруженные и исправленные особенности упаковки

1. Frozen-расположение ошибочно включало режим разработки Streamlit: явно установлен global.developmentMode=False.
2. Для разработки потребовалось явно указать Tcl/Tk из копии ресурсов в .build-venv/tcl. Для EXE ресурсы включены hooks PyInstaller.
3. Создание универсального urllib-opener в EXE вызывало FileNotFoundError при проверке локального сервера. Проверка переведена на прямой http.client.HTTPConnection к loopback, без HTTPS-handlers, сертификатов и системного proxy.
4. Smoke-тест при сбое теперь завершает только принадлежащий ему тестовый дочерний процесс; не оставляет незаметный сервер.
5. Остановка сервера проверена повторно: защищённый контрольный запрос корректно завершает Streamlit.

## Подтверждено до финальной пересборки

- EXE smoke-test: код завершения 0, HTTP готов за 1,56 секунды, штатная остановка.
- Проверка tests/check_packaged.py через реальные HTTP и WebSocket: в сборке открываются вход секретаря и форма судьи; исключений выполнения страницы нет; судейская форма не содержит панели итогов секретаря.
- Тесты интерфейса: первичная настройка, вход, отправка нулевых оценок, блокировка и четыре выгрузки — успешно.
- Финальный протокол сборки и тестов записывается следующим шагом после завершения проверок.

## Ограничения

На независимом чистом Windows-компьютере, в настоящем Excel/LibreOffice и с семью физическими смартфонами проверки не проводились. Не заявляется готовность PWA/offline-очереди, автоматической точки доступа, специальных максимумов и штрафов без утверждённой шкалы.
